NSBM SportsHub – Match Results Module
====================================

Files
- index.html: Results dashboard page
- style.css: Responsive navy-blue and green interface
- script.js: Search, filters, sample results, standings, fixtures, add/edit/delete and CSV export
- assets/: sports/facility visuals cropped from the NSBM SportsHub reference screenshots supplied for this project

How to run
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

Technology
HTML, CSS and JavaScript only. No PHP or database is used.

Important project note
This is a student-project prototype inspired by the supplied NSBM SportsHub mock-up screenshots. The scores, teams and dates in the starter data are examples for demonstration, not verified official NSBM match records. The app saves edits in the current browser with localStorage; it does not synchronise data across different users/devices.
